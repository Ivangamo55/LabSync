# Manuales de LabSync

- `Manual_de_Usuario_LabSync.pdf`: operación detallada por rol y plan de pruebas funcionales.
- `Manual_Tecnico_LabSync.pdf`: arquitectura, construcción, base de datos, pruebas, despliegue y soporte.
- Los archivos `.html` son las fuentes editables de los PDF.
- `estilos.css` contiene el estilo compartido de impresión.
- `capturas/` contiene 17 capturas renderizadas desde las ventanas Swing reales contra una copia temporal de la base de datos.

Los PDF fueron generados el 5 de agosto de 2026 con LibreOffice 26.2 y validados con `pdfinfo`, `pdftotext` y revisión visual de páginas representativas.
